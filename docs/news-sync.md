# 契約ニュースの手動取得

契約ニュースは毎朝5時の自動実行を行いません。ユーザーが「契約ニュース」画面の「最新情報を取得」を押したときに、本人が現在契約中のサブスクに対応する公式RSSと日本語ニュースを確認します。管理者も管理者メニューの「契約ニュースの手動取得」から同期できます。

ユーザー向けの同期・一覧・記事詳細・フィードバックAPIはログインとメール認証を必須とし、本人の有効な契約に紐づくサービスだけを対象にします。サービスの検索・Watch登録だけではニュースの対象になりません。短時間の連続実行にはレート制限があります。取得済み記事は保存され、ニュース画面で過去分も閲覧できます。

## 本番環境の確認

以前にニュース取得用のcronを設定していた場合は、crontabからニュースAPIを呼び出す設定を削除してください。既存の`run-daily-news.sh`は現在、公式価格同期だけを行い、ニュース取得は行いません。公式価格同期も不要な場合は、そのcron設定も削除してください。

```bash
crontab -e
crontab -l
```

手動同期に失敗する場合は、アプリの稼働状態、サービスマスターのRSS URL、外部フィードへの接続を確認してください。ニュースの同期に`GEMINI_API_KEY`は使用しません。
