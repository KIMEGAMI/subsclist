# SubscList 対象顧客・営業仕様

## 結論

SubscListの第一対象は、仕事と個人で10件以上の継続課金サービスを利用し、更新漏れ、解約判断、経費整理に時間を取られているフリーランス、副業者、個人事業主です。

一般消費者向け家計簿として銀行・カード自動連携サービスと競争するのではなく、「継続課金だけを判断可能な台帳にする」ことを提供価値とします。

## 対象顧客

- SaaS、クラウド、AI、制作、学習サービスを合計10件以上契約している
- 事業用と個人用の契約・支払いが混在している
- 更新日、無料期間、解約期限をスプレッドシートや記憶で管理している
- 月末や確定申告前に継続課金の仕事利用分を整理している
- 経理担当を置かず、自分で契約と支出を判断している

## 非対象

- 銀行口座・カードの全取引を自動取得する家計簿を主目的とする人
- 複数部署の承認、購買統制、ライセンス回収が必要な中規模以上の法人
- 税額計算や申告書作成までを単体で完結させたい人

## 購入理由

1. 更新・無料期間・解約期限を一つのカレンダーと通知で確認できる
2. 利用頻度と重要度を記録し、残す契約と見直す契約を判断できる
3. 契約ごとの仕事利用割合から、月次・年次の仕事利用分を見積もれる
4. CSVで契約台帳を持ち出し、会計整理や専門家への共有に使える
5. 解約チェックリストと証跡を残し、解約漏れを防げる

## 営業時の確認項目

- 現在いくつの継続課金を利用しているか
- 更新日や無料期間をどこで管理しているか
- 仕事利用と個人利用の切り分けに時間がかかっているか
- 直近1年で解約忘れや重複契約があったか
- 契約見直しを月に一度実施できているか

## 成果指標

- 初回24時間以内に5件以上登録したユーザーの割合
- 仕事利用割合を設定したアクティブ契約の割合
- 月次レポートを毎月閲覧するPremiumユーザーの割合
- 更新・解約期限通知から詳細画面へ遷移した割合
- 30日以内に見直しまたは解約計画を記録した割合

## 表示上の注意

仕事利用分はユーザーが入力した割合に基づく整理用の見積もりです。税務上の必要経費や控除を確定するものではなく、最終判断は利用者または税務の専門家が行います。
