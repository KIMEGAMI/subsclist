# SubscList（サブスクリスト）

**仕事で使うサブスクを、ひと目で整理するための無料Webサービスです。**

ChatGPTなどのAIツール、クラウドサービス、デザインツール……。便利だからと契約しているうちに、「結局、毎月いくら払っているんだっけ？」と思うことはありませんか。

SubscListは、そうした継続課金をまとめて管理し、支出や更新日、解約のタイミングを見直しやすくするために作りました。フリーランス、副業をしている方、個人事業主の方を主な対象にしています。

**現在はポートフォリオ兼公開サービスとして、全機能を無料で提供しています。** サブスクの登録件数にも上限はありません。

**サービスURL：** https://subsclist.kimegami.jp/

## 作ったきっかけ

実は、このサービスにはもう一つ目的があります。

私はこれまで主にPHPやLaravelで開発してきましたが、SubscListで使っているTypeScriptやNext.jsは、開発を始めた時点ではほとんど経験がありませんでした。

そこで、「自分が知らない言語やフレームワークでも、AIにコードを書いてもらいながら、Webサービスをどこまで作れるのだろう？」という実験をしてみることにしました。

実装はAIとのやり取りを中心に進めました。私は作りたいものや動かしたい仕様を伝え、生成されたものを動かして確かめ、うまくいかない部分を直していく役割です。

もちろん、AIに任せれば何も考えずに完成する、というわけではありません。思った通りに動かないこともありましたし、認証やデータベース、本番環境の設定など、調べながら何度もやり直した部分もあります。

それでも、普段使わない技術で一つのサービスを公開するところまで進められたのは、個人的に面白い経験でした。

**実験として作り始めたものですが、せっかくなら実際に誰かの役に立ってほしい。** そんな気持ちで無料公開しています。

## できること

- **サブスクの一元管理** — 契約中のサービス、料金、支払い周期などをまとめて記録
- **支出の見える化** — 毎月・年間の支払額や支払い状況を確認
- **仕事用と個人用の整理** — 仕事で使っている割合を記録し、仕事利用分の金額を把握
- **更新・解約期限の管理** — 更新日や無料期間、解約期限などを整理
- **契約の見直し** — 利用状況などをもとに、継続するか検討する契約を確認
- **CSV入出力** — 既存の一覧を取り込んだり、管理データを出力したりできます

※経費に関する集計は整理を補助するものです。税務上の判断は、ご自身で確認してください。

## このリポジトリについて

このリポジトリは、**未経験の技術をAI中心で使ってサービスを作る**という個人開発の記録でもあります。

AIでどこまでできるかを試すことが出発点でしたが、実際に動かしてみると、指示の出し方や仕様の整理、動作確認の大切さを改めて感じました。AIが書いたコードであっても、公開する以上は自分で確認し、責任を持って運用する必要があります。

完璧なサービスとは言えないかもしれませんが、サブスク管理に困っている方に気軽に使ってもらえたらうれしいです。

不具合や使いにくいところがあれば、サービス内のお問い合わせから教えてください。
